## Install on Windows (10 or 11, 64-bit)
1. Download `Setup_PortraitEdit_AI_Studio_v6.2.exe` and open it.
2. If a blue *Windows protected your PC* box appears, click **More info** > **Run anyway**.
3. Click **Next** until it finishes, then open PortraitEdit AI Studio from the Start menu or desktop.
4. Sign in (Google, or a code sent to your email). New accounts get a free trial.

## Install on macOS (12 or later)
1. Download `PortraitEdit_AI_Studio_v6.2_macOS_setup.zip` and unzip it.
2. Open `START_HERE_MAC.txt` inside it, then double-click `run.command`.
   The first start installs what the app needs (a few minutes, needs internet).
3. If macOS blocks it, right-click > **Open**.
